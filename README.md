# GitLab for Eclipse

This project hosts for the GitLab for Eclipse plug-in and related projects.

## Projects

### gitlab-eclipse-plugin-parent

The parent POM containing common build/dependency configuration across Maven module projects.

### gitlab-eclipse-plugin.core

The core GitLab for Eclipse plug-in project.

Learn more in the [project README](./gitlab-eclipse-plugin.core/README.md).

## gitlab-eclipse-plugin.site

Creates a P2 update site (e.g. Eclipse repository) which can be used to install GitLab for Eclipse plug-in.

Learn more in the [update site project README](./gitlab-eclipse-plugin.core/README.md).
